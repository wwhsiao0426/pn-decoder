    Amber-highlighted rows are the values this decoder currently covers (V310, Portable). Other rows document the full M-Level part number scheme for reference.

    Security HWID is not yet fully defined by the Verifone security team. Only one confirmed example is known: M208-350-11-EUA → H310-0007-02D0-17W-004-A0. This decoder reproduces that exact combination and shows "Pending Security Team definition" for everything else — it does not guess at how Color, SIM Type, PTID, or HW Revision would change the HWID.
