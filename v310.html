    V310 M-Level Part Number Options

    M208-def-gh-xxn

    d = Major Hardware Revision

    0Multi-Lane
    1PINpad
    2Countertop
    3Portable
    4Mobile
    5Petro
    7Unattended
    8Fiscal ECR
    9Reserved

    e = Radio Module & OS (VAOS = Android, VOS = Linux)

    0QCS2290, DB WiFi 802.11ac, Bluetooth 5.0, VOS3 — Linux, WiFi only (V310-E)
    1QCS2290, DB WiFi 802.11ac, Bluetooth 5.0, AVOS — Android, WiFi only (V310-A)
    2Reserved
    3Reserved
    4QCM2290, EM or NA, 4G LTE, DB WiFi 802.11ac, Bluetooth 5.0, VOS3 — Linux, 4G LTE (V310-E)
    5QCM2290, EM or NA, 4G LTE, DB WiFi 802.11ac, Bluetooth 5.0, VAOS — Android, 4G LTE (V310-A)
    6Reserved

    This single digit jointly encodes OS (Android/VAOS vs Linux/VOS3) and Radio Module (4G LTE vs WiFi only). Row 0's chip is shown here as QCS2290 (WiFi-only) to match the 2×2 pattern confirmed by rows 1/4/5 — the source doc's row 0 literally repeats row 4's "QCM2290...4G LTE" text verbatim, which looks like a copy-paste artifact rather than an intentional 5th combination.

    f = Payment Options

    0EMV, CLTS, PSCR, MSR, NO PTID
    1EMV, CTLS, PSCR, MSR, PTID

    g = Hardware Options

    0Reserved
    10.3MP FF Rear Camera, Haptics, SIM, SIM/SAM, EBS 100 Keypad
    20.3MP FF Rear Camera, Haptics, eSIM, SIM, SAM, EBS 100 Keypad
    3Reserved

    h = Android Memory Config

    0Reserved
    11GB DDR / 8GB Flash
    2Reserved

    xxn = Country code and localization

    EUAEM region, White housing — the only country code defined for V310 so far

    Includes customization for labelling, colour, and branding, and for eSIM carrier configuration — same general scheme as the other decoders on this site. Other country codes and colors aren't defined for V310 yet; they'll be added here once Verifone defines them. Navigator Stencil and HW Revision are also not yet defined for V310 (shown as N/A).

    Amber-highlighted rows are the values this decoder currently covers (V310-A / V310-E, Portable). Other rows document the full M-Level part number scheme for reference.

    Security HWID is not yet fully defined by the Verifone security team. Only one confirmed example is known: M208-350-11-EUA → H310-0007-02D0-17W-004-A0. This decoder reproduces that exact combination (Android, 4G LTE, no PTID, SIM) and shows "Pending Security Team definition" for everything else — it does not guess at how OS, Radio Module, or SIM Type would change the HWID.
